The official Java 17 SDK for the XYO.Financial transaction enrichment API. A valid API key is available from the [XYO dashboard](https://xyo.financial/dashboard).

## Requirements
* Java 17 or newer
* Maven (for building from source)

## Build and test
```sh
mvn clean install --file xyo-sdk/pom.xml
```

## Usage
```java
import com.xyo.financial.ClientConfig;
import com.xyo.financial.XyoClient;
import com.xyo.financial.EnrichmentRequest;
import com.xyo.financial.EnrichmentResponse;
import com.xyo.financial.EnrichmentCollectionStatus;
import java.util.List;

public class App {
    public static void main(String[] args) {
        // Instantiate the config using the builder
        ClientConfig config = new ClientConfig.Builder("YourAPIKeyFromXYO.FinancialDashboard")
                .connectTimeoutMs(5000)
                .requestTimeoutMs(30000)
                .build();
                
        XyoClient client = new XyoClient(config);

        EnrichmentResponse result = client.enrichTransaction(new EnrichmentRequest("COSTA PICKUP", "GB"));
        System.out.println(result.getMerchant());

        var bulk = client.enrichTransactionCollection(List.of(
                new EnrichmentRequest("COSTA PICKUP", "GB"),
                new EnrichmentRequest("STRBUKS GREENWICH", "GB")
        ));
        
        EnrichmentCollectionStatus status = client.enrichTransactionCollectionStatus(bulk.getId());
        System.out.println(status);
    }
}
```

Requests that fail at the transport layer, return a non-2xx status, or contain an invalid response throw `XyoException`. `location` and `address` may be null because the service may return JSON `null`. When an HTTP error occurs, you can inspect the response body via `exception.getResponseBody()`.

## Installation & Integration

The Java SDK can be integrated into your project using Maven or Gradle.

### 1. Maven (Recommended)

Since this package is currently distributed via source, you must first build and install it into your local Maven cache:

```sh
git clone https://github.com/syniol/xyo-sdk-java.git
cd xyo-sdk-java
mvn clean install --file xyo-sdk/pom.xml
```

Then, add the dependency to your project's `pom.xml` (replace `1.0.0` with the actual release version you built, or `1.0.0-SNAPSHOT` if building directly from the SNAPSHOT source):
```xml
<dependency>
    <groupId>com.xyo.financial</groupId>
    <artifactId>xyo-sdk</artifactId>
    <version>1.0.0</version>
</dependency>
```

### 2. Gradle
After installing the library to your local Maven repository (as shown above), add the following to your `build.gradle`:

```gradle
repositories {
    mavenLocal()
    mavenCentral()
}

dependencies {
    implementation 'com.xyo.financial:xyo-sdk:1.0.0'
}
```
