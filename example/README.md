# XYO SDK Example (Java)

This directory contains a basic example application demonstrating how to integrate and use the XYO Java SDK using Maven.

## ⚙️ Requirements
* Java 17 or newer
* Maven

## 🚀 Running the Example

Compile and run the application:
```sh
mvn clean package exec:java -Dexec.mainClass="financial.xyo.example.Main"
```
